# Overview:
MedHub is a medical appointment booking web application designed and developed collaboratively using Ruby on Rails. The intention was to apply full-stack development skills learned throughout a web development bootcamp at [Le Wagon](https://www.lewagon.com) and to correctly use GitHub to contribute to a collaborative repository.

## Process:
Initial stages of planning and stuctural design comprised of mapping the desired user stories.
The database was then designed and UI concepts were drafted. 

The application was developed using a Model-Controller-View workflow to implement CRUD actions in the user experience.

## For future consideration:
Use of AI to generate code resulted in functional but ultimately impractical code being used to create join tables; new models were generated to clean up the database and produce an outcome with scaling potential.

## Stack:
Ruby on Rails, JavaScript, CSS, HTML, Figma, Heroku, SQL, Git
